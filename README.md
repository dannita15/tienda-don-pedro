# Tienda Don Pedro

Tienda de barrio en Itagüí. Don Pedro quiere llevar el control de sus productos y de sus clientes.

## Archivos

- `productos.txt`: productos y precios.
- `clientes.txt`: clientes frecuentes.
- `vetas.txt`: Ventas del dìa.
- `fiado.txt`: Fiados en la tienda de don pedro.
- `descuentos.txt`: descuentosa a los clientes frecuentes.

## Domicilios
atendemos desde las 8:00 am hasta las 6:00 pm de lunes a sabado
cubrimos todo el valle de aburra
